# Pokemon Top Trumps

A digital Top Trumps card game featuring Pokemon. Compare stats like HP, Attack, Defense, and Speed to win your opponent's cards.

## Deck

A 40-card draft lives in `data/deck.json`. Stats are official base stats, height, and weight from [PokeAPI](https://pokeapi.co). Playable categories: HP, Attack, Defense, Sp. Attack, Sp. Defense, Speed, Height, Weight.

## Planned features

- Two-player rounds: pick a stat, highest wins
- Simple web UI to play in the browser
